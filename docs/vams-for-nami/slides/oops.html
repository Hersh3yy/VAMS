An honest mistake

The keys are written in plain sight

📖

Today

The secret keys are stored as normal readable words. Anyone who got into the box could read them straight off, like a password written on a sticky note.

🔒

The fix

Scramble each key into a jumble before saving it. VAMS can still check your key, but a thief would only find jumble, not the real keys.

Hiren has written this down as a job to do. Telling the truth about a weak spot is how it gets fixed — pretending it is perfect is how it stays broken.

Honesty slide: a real known weakness. Scrambling a secret so even the owner of the box cannot read it back is called hashing. Ask Nami: why is it safer to store a jumble of a password than the password itself?
